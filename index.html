How each column was judged

Process. A run passes when run.sh finished every step and wrote done: fresh Gutenberg draft, plan and apply, layout, the se tool reviews, every rule wave, list of illustrations, modernization, diacritics, dashes, lint with campaign resolution, the source audit, and the research package. A failure is reported at the step where the run stopped. Runs were never resumed by hand, and no generated book was edited by hand. When a run failed, the owning pass or checker was fixed in se-llm, reviewed and gated by just ci, and the book was started again from a fresh draft.

Models. Every model step used the Claude light tier (Haiku) at high effort. Sonnet and Opus appear only where se-llm's existing floors route difficult items and checks to them, such as the lint resolver and its independent checker, which use the strong tier. The per-attempt table lists the models that the run's own usage records name.

Source audit. The auditor compares the final reading text with the captured Gutenberg file, in reading order. It accepts only these changes: spelling and hyphenation changes that the checked modernization pass recorded as evidence, producer-approved omissions, the exact drama projection of speaker labels and bracketed stage directions to typed persona cells and stage-direction elements, and a short list of SE typography transforms. Any other added, missing or changed text is an unresolved record. A clean audit means no unresolved record remains. A count of unresolved records does not by itself show lost or added literature; the examples show what each one is.

Lint. se lint runs on the finished book. Errors and manual-review messages go to an owner model, which proposes exact edits or a reasoned disposition. An independent checker approves or rejects each decision and gives a reason when it rejects. The owner gets one revision per round, at most two repair rounds run, and the checker's rejection is final. The column passes only when the campaign check finds no unresolved finding.

EPUB build. se-llm prepare-book package copies the finished book, fills the publication metadata truthfully, and runs se build --check, which includes EPUBCheck and the W3C validator. The copy says it is an unofficial research package generated by se-llm from the Project Gutenberg edition. It names the transcribers that the Gutenberg file credits, invents no producer, scan or artist, and uses the plain typographic cover from the SE template with no artwork. One EPUBCheck message is accepted as a false positive: aria-labelledby on the table of contents navigation, a confirmed EPUBCheck bug (w3c/epubcheck issue 1726, fixed by pull request 1727). Every other message blocks.

Reader. The built EPUB was opened in a reader inside the isolated gui-sandbox session, never on the owner's desktop, and the table of contents, a body page and the end matter were inspected. "Not checked" means this did not happen.

Agreement with SE. Two numbers compare the proof with the pinned Standard Ebooks edition. Markup agreement counts semantic elements, such as abbreviations, foreign phrases and stage directions, by kind and text. Reading-text agreement counts words and punctuation marks that appear in the same order in both books. These are not scores of correctness. SE's editors corrected Gutenberg typos, restyled headings, and added or removed material; the proofs keep the Gutenberg text. Where SE differs, the examples show whether the cause is SE editing, an intentional scope difference, or a proof defect.

Limits of this report

  • Each book is one Gutenberg edition. Agreement with SE is limited where SE used a different source, translation or edition; the register notes these per book.
  • The Around the World in Eighty Days translation is weak, and SE's Devil's Dictionary and Tao Te Ching are complex custom productions. Their agreement numbers are shown but say little about se-llm.
  • Costs are what the tools report: rule calls from the dispatch usage records, preparation steps from their logs rounded to the cent, and lint resolution exactly. Failed attempts are included. They are not a provider bill.
  • The reader check is a visual spot check, not a page-by-page proofread.
  • Attempts before e2e49 used older revisions and are linked as history only. The repaired branches from e2e40 and e2e41 were edited by hand and are excluded from every count.
